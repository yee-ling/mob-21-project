Sports & Wellness Booking App - A booking app with a dynamic time-grid interface built using Jetpack Compose and Firebase

Introduction: 
Sports & Wellness Booking App is a mobile application designed to simplify the process of booking time slots for sports and wellness activities. The app provides users with a structured time grid interface, allowing them to easily view availability and reserve slots in an organized manner.
Built with a focus on usability and real-time data handling, this app helps streamline booking management while providing a clear and intuitive user experience.

Features: 
- Users can browse and explore available sports classes and wellness sessions.
- Users can select and reserve available time slots through an interactive time grid interface.
- Displays schedules in a clear, structured format, making it easy to view availability at a glance.
- Utilizes Firebase Firestore to sync booking data instantly across users.
- Users can create and manage their bookings efficiently.
- Built using Jetpack Compose for a responsive and dynamic user experience.

Technologies Used: 
- Kotlin – Main programming language
- Android Studio – Development environment
- Jetpack Compose – Modern UI toolkit
- Firebase Firestore – Real-time cloud database
- Firebase Authentication – User authentication
- MVVM Architecture – Clean and maintainable app structure

Usage: 
- Log in or register an account
- View available time slots in the grid
- Select a preferred time slot
- Book and manage your reservations
- See updates reflected in real time
